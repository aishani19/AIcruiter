🚀 AIcruiter – AI-Powered Interview Preparation Platform

AIcruiter is an intelligent interview preparation platform designed to help users practice, improve, and evaluate their interview performance using AI-driven insights. It combines resume-based question generation, real-time feedback, and interactive practice sessions to simulate a realistic interview experience.

✨ Key Features

🎯 AI-Generated Interview Questions

Generates personalized questions based on user resumes using LLMs

🧠 Resume-Based RAG System

Uses retrieval-augmented generation to create context-aware questions
🎤 Audio & Speech Analysis

Evaluates confidence, clarity, and filler words during responses

📊 Performance Feedback System

Provides structured feedback and scoring for improvement

🏆 Leaderboard & Gamification

Encourages continuous learning through ranking and scoring
